# Kainat Faisal — Personal Portfolio

A responsive personal portfolio website built to showcase my skills, projects, education, and interests in web development and software engineering.

## Live Website

[View My Portfolio](https://kainat23fa.github.io/kainat-portfolio/)

## About the Project

This portfolio website was created as a personal web development project to present my background, technical skills, projects, and contact information in a clean and responsive design.

The website is built using HTML, CSS, and JavaScript, with a focus on responsive design, user interaction, and a simple user-friendly interface.

## Features

* Responsive single-page portfolio
* Home/Hero section
* About Me section
* Skills section
* Projects showcase
* Contact form with client-side validation
* GitHub and LinkedIn links
* Dark/Light mode
* Mobile navigation menu
* Back-to-top button
* Responsive layout for different screen sizes
* Interactive JavaScript features

## Technologies Used

* HTML5 — Website structure and semantic elements
* CSS3 — Styling, layout, responsive design, and animations
* JavaScript — DOM manipulation, events, form validation, and interactive features
* Git — Version control
* GitHub — Source code repository
* GitHub Pages — Website deployment

## Responsive Design

The portfolio is designed to work across different screen sizes, including:

* 360px — Mobile
* 768px — Tablet
* 1440px — Desktop

Media queries and responsive CSS techniques are used to provide a consistent experience across devices.

## How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Kainat23FA/kainat-portfolio.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

No additional installation or dependencies are required.
